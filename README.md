# RupeePay

A modern, full-stack financial application.

## Prerequisites

- Node.js
- npm

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Set the environment variables in `.env.local`.

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.
